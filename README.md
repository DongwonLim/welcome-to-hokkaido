# 「ようこそ、北海道へ」(ver.2 開発中)

## プロジェクト説明
「ようこそ、北海道へ」は、日本の北海道を紹介するブログサイトです。このサイトでは、北海道でおすすめする食堂、居酒屋、カフェ、キャンプ場、観光地を紹介しています。サイトのURLを通じて、Google Mapsで実際の場所を確認できるようになっています。

---

## 主要サービス
- **食堂、居酒屋、カフェ、キャンプ場、観光地の紹介**  
  北海道の地域ごとのおすすめスポットを詳細に紹介します。
  
- **Google Mapsとの連携**  
  紹介した場所はGoogle Mapsで簡単に位置確認できます。
